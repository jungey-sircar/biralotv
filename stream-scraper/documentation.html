API reference / Go service

Stream links, three modules, one endpoint.

Resolve movies and TV episodes into playable HLS links. Pick a server module, pass a TMDB id, and the proxy keeps the upstream URLs behind stable local paths.

plain JSON no auth default port 8080

Overview

01

The service exposes three interchangeable server modules. server1 is the default and can hop between mirrors. server2 walks a primary catalog and falls back to a secondary catalog. server3 uses the secondary catalog only.

server1 Default. Tries the requested mirror first, then up to three alternates. default
server2 Primary catalog first, secondary catalog as fallback. fallback
server3 Secondary catalog only. No fallback to the primary catalog. single path

Quick start

02

Run from the project folder. Go 1.25 or newer is required.

shell
cd stream-scraper
go mod download
go run .

Build a single binary when you are done testing.

shell
go build -o stream-scraper .
./stream-scraper
health check
curl http://localhost:8080/healthz

Configuration

03

All configuration is read from environment variables at startup.

VariableDefaultPurpose
PORT8080HTTP listen port.
PUBLIC_BASE_URLrequest hostBase URL placed in returned stream links. Set it behind a reverse proxy.
SCRAPER_UPSTREAM_PROXYemptyOptional HTTP or SOCKS5 proxy for upstream requests.
SCRAPER_UPSTREAM_PROXY_HOSTSemptyComma separated host suffixes that should use the proxy. Empty means all requests use it.
example
PORT=9000 \
PUBLIC_BASE_URL=https://scraper.example.com \
SCRAPER_UPSTREAM_PROXY=socks5://127.0.0.1:1080 \
SCRAPER_UPSTREAM_PROXY_HOSTS=api.example.com,media.example.com \
./stream-scraper
Reverse proxy: set PUBLIC_BASE_URL to the public origin. Otherwise returned links use the request host and protocol.

Endpoints

04

Five routes. Two resolve media, one resolves proxy tokens, one lists the modules, one reports health.

MethodPathPurpose
GET/healthzProcess health and uptime.
GET/v1/serversList the three server aliases.
GET/v1/movies/{tmdb_id}Resolve a movie.
GET/v1/shows/{tmdb_id}/seasons/{season}/episodes/{episode}Resolve a TV episode.
GET/v1/stream/{token}Playback proxy for generated links.

07

Query parameters

Stream proxy

09
GET/v1/stream/{token}

Internal playback route. The proxy resolves the token, applies the required upstream headers, and forwards the bytes. HLS playlists are rewritten so variants, keys, init maps and segments all point back through this route.

BehaviourDetail
Range requestsForwarded, so seeking works.
HLS rewriteRecursive for playlists, variants, keys and segments.
Token lifetimeFour hours, held in memory.
Token identityStable for a media path across rotating query strings.
request
curl 'http://localhost:8080/v1/stream/14559efd36019650cc'
playlist response
#EXTM3U
#EXT-X-STREAM-INF:BANDWIDTH=6113605,RESOLUTION=1440x1080
http://localhost:8080/v1/stream/6ca530d4c2cbded6d6
#EXT-X-STREAM-INF:BANDWIDTH=16214159,RESOLUTION=2880x2160
http://localhost:8080/v1/stream/283b768ae4e49b7a24
Do not construct tokens. Use the URLs returned by the movie or episode endpoint. A missing or expired token returns stream_not_found.

Response model

10

Movie and episode endpoints share one response shape.

FieldTypeNotes
typemovie or tvMedia kind.
tmdb_idintegerNumeric TMDB id.
seasonintegerTV only.
episodeintegerTV only.
serverstringserver1, server2, or server3.
resolved_bystringMirror name, or primary / secondary.
playliststringMaster HLS URL through the proxy. Optional.
streamsarrayObjects with quality and url. Empty when none are exposed.
thumbnailsstringOptional proxied thumbnail URL.

Errors

11

Every error is JSON with a stable code and a short message.

error shape
{
  "error": {
    "code": "no_streams",
    "message": "No stream was found for this title on the requested server."
  }
}
StatusCodeMeaning
400invalid_tmdb_idThe id is not a positive integer.
400invalid_serverUse server1, server2, or server3.
400invalid_episodeSeason is zero, or season or episode is not numeric.
404no_streamsThe upstream has no source for this title.
404stream_not_foundThe proxy token expired or never existed.
502upstream_errorAn upstream provider or CDN returned an error.
504upstream_timeoutAn upstream provider did not answer in time.

Playback

12

Fetch the movie or episode response, then hand playlist to hls.js. The proxy sends CORS headers, so the page can live on another origin.

javascript
const info = await fetch(
  "http://localhost:8080/v1/movies/19?server=server2"
).then((response) => response.json());

const video = document.querySelector("video");
const hls = new Hls();
hls.loadSource(info.playlist);
hls.attachMedia(video);

VLC works with the same playlist URL.

shell
vlc "http://localhost:8080/v1/stream/14559efd36019650cc"

Notes

14

Operational details that matter when this moves from localhost to a host.

TopicDetail
Token lifetimeFour hours, in memory. Restarting the process invalidates every link.
Multiple instancesThe token store is process local. Use one instance or sticky routing.
Upstream expiryProvider URLs can expire before the token TTL. Fetch a fresh response when playback stops.
Blocked hostSet the upstream proxy variables first. Scope them to the hosts that need the proxy.
Provider changesCatalog pages and source APIs change without notice. A failing module usually means its page shape changed.
